This is an interactive guide as to how to run the simulator!

First: You will need working Python 3 (Pycharm preferable, not required), and the additions Matplotlib, NumPy and SciPy

Open a terminal in your project folder and using pip, install Matplotlib, NumPy and SciPy:

1. Write pip install numpy scipy matplotlib

2. Open your simulator file in Python

3. Run using green play button, a prompt will appear, answer either 1, 2, 3, 4 and respond to subprompts.

4. A simulation screen will pop up and display your simulation, use the mouse to rotate and interact, you can zoom in or out.

5. Close the simulation and then you can rerun.

A brief Guide:

1=One charge electric field (Try 1e-9 to test if it works)

2=Two charge electric field (Try 1e-9 and -1e-9 and 10)

3=Gaussian Sphere(Try 1e-9, 5 and then probe (1,0,0)_

4=Dirac Delta Cluster (remember still mostly cosmetic, try 1e-9)

A quick note: A charge of q=0 will lead to an error message, as will a distance of 0 on function 2
